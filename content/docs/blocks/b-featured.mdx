## Custom stats

Pass your own metrics to the stats row:

```tsx
<FeaturedBlock
  stats={[
    {
      label: "Monthly Revenue",
      trend: "+8.2%",
      trendUp: true,
      value: "$42,500",
      subtitle: "Up from last month",
      description: "Based on completed transactions",
    },
    // ...
  ]}
/>
```

## Custom chart data

```tsx
<FeaturedBlock
  chartTitle="Page Views"
  chartDescription="Last 90 days"
  chartData={[
    { date: "Jan 1", visitors: 1200 },
    { date: "Jan 8", visitors: 2400 },
    // ...
  ]}
  chartRanges={["Last 90 days", "Last 30 days", "Last 7 days"]}
/>
```

## Custom table data

```tsx
<FeaturedBlock
  tableTabs={[
    { label: "All" },
    { label: "Active", count: 5 },
    { label: "Archived" },
  ]}
  tableRows={[
    {
      id: "1",
      header: "Introduction",
      sectionType: "Narrative",
      status: "done",
      target: 10,
      limit: 8,
      reviewer: "Alice Johnson",
    },
  ]}
  totalRows={42}
/>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `stats` | `FeaturedStat[]` | See defaults | Four stat cards at the top |
| `chartTitle` | `string` | `"Total Visitors"` | Chart card heading |
| `chartDescription` | `string` | `"Total for the last 3 months"` | Chart card subheading |
| `chartData` | `FeaturedChartPoint[]` | Sample data | Area chart data points |
| `chartRanges` | `string[]` | `["Last 3 months", ...]` | Time range tabs |
| `tableTabs` | `FeaturedTableTab[]` | See defaults | Table section tabs |
| `tableRows` | `FeaturedTableRow[]` | See defaults | Table row data |
| `totalRows` | `number` | `68` | Total row count for pagination |
| `rowsPerPageOptions` | `number[]` | `[10, 20, 50]` | Rows per page options |

## Specs

```md
# Mint — Featured Block Specs

## Component
- name: b-featured
- file: registry/mint/b-featured.tsx
- installs to: components/ui/b-featured.tsx
- npm dependencies: recharts, lucide-react
- registry dependencies: card, chart, tabs, button, e-data-table

## What is it
A full-width dashboard block composed of three stacked sections: a row of
stat cards, an area chart with time-range tabs, and a paginated data table
with filterable tabs. Use it as the primary view of a dashboard or analytics
page. All three sections accept data via props so the block can be dropped in
with any domain — athletes, users, orders, documents.

## Visual identity
Clean and data-forward, now carried in Mint's fresh green palette. Each
section is a Card with a soft, glassy border (60% opacity) and generously
rounded corners. Stat cards use a two-row layout: the metric value at large
type, trend badge (green/red) top-right, subtitle and description below. The
chart uses a single area series with a soft green gradient fill and a
hairline stroke. The table uses minimal row dividers with no background fill
— emphasis is on the data, not the chrome.

## Structure
- StatCards row: 4 cards, 1 col → 2 col (sm) → 4 col (xl)
- ChartSection: full-width Card with Tabs for time range, ResponsiveContainer
  wrapping recharts AreaChart
- TableSection: full-width Card with Tabs for status filters, DataTable with
  column header sort, filter input, row selection, and pagination

## Stat card anatomy
Each stat in FeaturedStat renders:
- label: text-sm text-muted-foreground (top-left)
- trend: text-xs font-medium, TrendingUp (emerald) or TrendingDown (red) icon
- value: text-2xl font-bold leading-none
- subtitle: text-sm font-medium with repeat icon
- description: text-xs text-muted-foreground

## Chart section
Built with recharts AreaChart inside ResponsiveContainer (height 220):
- Single Area series, type="monotone", gradient fill (5% → 2% opacity)
- CartesianGrid vertical={false} for horizontal-only grid lines
- XAxis: tickLine=false, axisLine=false for a clean baseline
- Tooltip: white card with border, 8px radius

## Table section
Uses the e-data-table element with tabs for status filters:
- Default columns: header, sectionType, status (badge), target, limit, reviewer
- Status badge colours: done (emerald), in-process (blue), pending (yellow), cancelled (red)
- Filter input filters across all string columns
- Pagination via DataTable's built-in rowsPerPage

## Conventions
- Pass all four sections as props — do not import sub-components separately
- chartData points must have { date: string, visitors: number } shape
- tableRows must satisfy FeaturedTableRow (id, header, sectionType, status,
  target, limit, reviewer)
- Use totalRows to reflect the full dataset size when rows are paginated server-side
- The block is "use client" — wrap in a Suspense boundary if lazy loading
```
